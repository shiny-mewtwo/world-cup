# World Cup archive

This repository contains a public static archive. Preserve public predictions,
scoring and tournament results. Never add accounts, emails, payments, drafts,
credentials, original database backups or administrative notes.

Run builds/tests on alex-macbook-pro per shared instructions. `npm run build`
uses only `data/public-archive.json` and produces `out/`. The workflow deploys
that directory to GitHub Pages. There is no production runtime database.
